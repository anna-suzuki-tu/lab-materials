なぜ「OS」なのか

同じ時間を研究に使っているのに、なぜ差が出るのか。データはあるのに主張がない「迷走」と、問いの設計に命をかける「突破」——この差は才能ではなく、「型」の差です。私たちが最初にインストールするのは、意図的な問い・構造化された工程・再現性のある成果からなる「研究用OS」です。柱は3つ：

  1. 体系化 / Systematization — 個人のセンスをシステムに置き換える
  2. 共通言語 / Common Language — Paper Card・Inquiry Cycle をラボ全員の共通言語にする
  3. 再現性 / Reproducibility — 誰でも高い品質の成果を再現できるようにする

OS で再現したいのは、成果ではなく成長です。誰でも探究できる人になる——その過程を再現可能にするために、文化は偶然ではなく構造（Structure）→ 習慣（Habit）→ 文化（Culture）の順に設計します。行動の判断基準となる4つの価値はポータルの Lab Values を見てください。
