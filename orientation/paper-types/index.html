LAB OS — CHAPTER 05

論文タイプ｜信念のスコープと形式

Paper Types — 信念の形式は複数ある

論文タイプは「格」ではない。信念のスコープが違うだけ

Original / Review / Technical / Short——これらは横並びで、上下関係はありません。同じ「信念」を、どのズームレベルで固定するかの違いです（Same "belief," different zoom levels）。「Originalが偉くてShortは格下」という発想を、まず捨ててください。

4つの基本形式

形式役割
Original新しい主張 — New Claim
Review問いの再設計 — Reframing Questions
Technical方法の提示 — Methodological
Short限定的主張 — Limited Claim

形式は道具であって序列ではありません。

発表の場の違い — 片方の軸はスピード、片方は厳密さ

  • 💬 Conference — 議論を始める場。スピード重視
  • 📄 Journal — 厳密に検証する場。厳密さ重視
  • 🎓 Thesis — 統合された説明責任の場

場によって役割が違います。使い分けてください。

研究フェーズによって、出す論文タイプは変わる

  1. 探索 / Exploration — Short・Technical で小さく固定する
  2. 安定 / Stability — Original で新しい主張を出す
  3. 軸確立 / Establishment — Review で問いを再設計する
研究フェーズ典型的な論文タイプ
仮説探索期Short / Technical
仮説安定期Original
軸確立期Review / Perspective

博士は軸を持つ。その一つの形がReviewです。また、Thesisは枚数ではなく一貫した信念体系——Paper 1 → Paper 2 → Paper 3 をつなぐ一貫したストーリーです（詳細は第9章で）。

4つの基本形式に、2つを足す

原著・レビュー・テクニカル・ショートの4つに加え、ケーススタディ／フィールド報告（特定条件下での検証。一般化の限界を明示する）とパースペクティブ／論説（立場と方向性を提示する。研究軸が確立してから）があります。6タイプそれぞれの目的・必須要素・よくある失敗・いつ選ぶかは付録 05-Aに。

形式から選ぶな。問いから選べ

Question → Format → Venue

  1. Question — まず問い。MAP（地図）を持つ
  2. Format — 問いに合う形式を選ぶ
  3. Venue — 最後に発表の場を決める

「あの学会に出したいから、こういう論文を書く」——順番が逆だと、だいたい迷います。

著者・誠実さ・再現性の原理は06 研究の責任で、投稿実務は Lab Forum Lectures「Writing Papers」で扱います。
この章のまとめ：論文タイプに序列はなく、信念のスコープが違うだけ ／ 場によって役割が違う（Conference・Journal・Thesis）／ フェーズに応じてタイプを使い分ける ／ 選ぶ順番は Question → Format → Venue ／ 論文タイプを選ぶことは、自分の信念のスコープを決めること
