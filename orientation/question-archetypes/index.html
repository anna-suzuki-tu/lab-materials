問いの型｜Question Archetypes

Question Archetypes — 7つの型と、型ごとに決めること
研究分野が違っても、問いの構造はある程度共通しています。自分の研究がどの「型」に属するかを確認し、その型が要求する要素が決まっているかを見てください。

「決めること」とは何か

各型の「問いを成立させるために決めること」は、論文に書く項目ではありません。問いを1文にする前に決めておく要素です。推定型で「何を推定するか」「何から推定するか」が決まっていなければ、問いは書けません。

決まると、二つのことが自動的に決まります。一つは Core Question の中身（03章 Step 2-3）。もう一つは必要なデータ——何を、どの条件で観測すべきか（03章「問いが決まると、必要なデータが決まる」）。要素が決まらないまま実験に入ると、取ったデータが問いに答えられないことが後でわかります。

A｜推定型｜Inference / Estimation

"Can we infer X from Y?"

観測データから、直接見えない構造やパラメータを推定する問い。

問いを成立させるために決めること：X（推定したいもの）は何か／Y（観測できるもの）は何か／識別性はあるか／不確実性はどう扱うか

B｜機構型｜Mechanism / Causality

"What controls X?"

ある現象を支配する因果構造を明らかにする問い。

問いを成立させるために決めること：「支配する」をどう定義するか／因果と相関をどう区別するか／代替説明は何か

C｜妥当性型｜Validity / Boundary

"Under what conditions is the model/assumption valid?"

モデルや仮定の適用範囲を問う。

問いを成立させるために決めること：何が仮定か／どの条件で破綻するか／何と比較して妥当と言うのか

D｜不確実型｜Uncertainty / Sensitivity

"How sensitive is the prediction to uncertainty?"

予測や判断が不確実性にどの程度影響されるかを問う。

問いを成立させるために決めること：どの不確実性を扱うか（構造／パラメータ／データ）／意思決定とどう関係するか／単なる分散評価で終わっていないか

E｜スケール型｜Scale-linking / Generalization

"How does micro affect macro?"

小スケールのプロセスが大スケールの挙動にどう影響するか。

問いを成立させるために決めること：どのスケールを接続するか／何が保存され何が失われるか／一般化可能性はあるか

F｜動態型｜Dynamics / Evolution

"How does X evolve over time?"

時間的変化や相転移を扱う問い。

問いを成立させるために決めること：状態変数は何か／安定性・臨界点はあるか／初期条件依存性は

G｜設計型｜Design / Intervention

"How should we design a system/process to achieve X?"

構造理解を踏まえて設計に踏み込む問い。

問いを成立させるために決めること：目標状態は何か／設計原理は何か／操作と操作的誘導の境界は

使い方

  1. 自分の問いを1文で書いてみる
  2. 上の型のどれに最も近いか選ぶ
  3. その型の「決めること」が決まっているか確認する
  4. 決まっていない要素があれば、決めてから1文を書き直す

型が決まらない場合は、問いがまだ曖昧です。要素が決まらない場合は、Step 1（分野を調べる）に戻ってください。

分野別の例

理解のための例です。型は上の A〜G で考えてください。

  • 地熱貯留層工学：温度応答から表面積を推定できるか（A）／単純化モデルはどこまで信頼できるか（C）／構造不確実性は予測にどう影響するか（D）／貯留層性能は時間とともにどう変化するか（F）
  • 地球科学：何が透水性進化を支配するか（B）／実験スケールはフィールドに一般化できるか（E）／応力–透水性のフィードバックは（B/E）
  • AI：A は B より優れるか（C 派生）／収束や汎化は保証できるか（B/C）／分布シフト下で一般化できるか（D/E）
  • 合意形成・社会システム：どの条件で合意が生まれるか（F）／なぜ分かり合えないのか（B）／共通の問いはどう立ち上がるか（F/E）
  • 感性工学：ワクワクは何次元で構成されるか（B）／物理属性は感情にどう写像されるか（A/B）／どんな設計が主体性を高めるか（G）

型が決まると決まること

何を書くべきか／どのジャーナルに出すべきか／どのデータが必要か。型を意識するのは流行に乗るためではなく、自分の問いの構造を明確にするためです。

文献の探し方と管理（Step 1 の実務）

何を集めるか：主要なレビュー論文（分野の信念）、直近3〜5年の代表論文5本以上（問いの型と暗黙の前提）、投稿候補の雑誌から似た論文3〜10本（書き方のパターン）

探し方：Consensus（質問文で検索、最初に試す）／Google Scholar（引用数、Geothermal AND "fluid transport" のような演算子）／Web of Science・Scopus（引用関係をたどる）／arXiv（プレプリント）。位置づけの調査では、参考になった論文の References と Cited by を追うのが最も効きます。

Comparison Table に落とす：先行研究／その主張／隠れた前提／限界／自分の更新。

管理：Zotero（無料、ブラウザ拡張、共有に強い）か Mendeley（PDF 整理、Word/LaTeX 連携）。1論文につき「自分の問いにどう関係するか」を1行残す。

投稿先を意識する：雑誌の Scope を理解し、Journal finder で候補を絞る。査読期間などの経験談は Scirev。
